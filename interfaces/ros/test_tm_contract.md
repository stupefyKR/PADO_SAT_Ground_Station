# ROS 시험 화면 입력 계약

이 문서는 ROS 화면을 검토하기 위한 정규화된 **시험 TM 스냅샷** 형식이다.
실제 TM 패킷, GNSS 수신기 출력, CubeADCS 자세 TM의 필드 정의가 아니다.
브라우저에서만 파일을 해석하며 서버 저장소나 경보 증적에는 기록하지 않는다.

```json
{
  "type": "TEST_ONLY_TM_SNAPSHOT",
  "non_operational": true,
  "received_utc": "2026-10-23T09:00:00Z",
  "sensors": [{
    "id": "bus_v", "name": "버스 전압 예시", "group": "전원",
    "unit": "V", "lower": 25, "upper": 31,
    "samples": [
      {"utc": "2026-10-23T08:59:00Z", "value": 28.1},
      {"utc": "2026-10-23T09:00:00Z", "value": 28.3}
    ]
  }],
  "attitude": {
    "utc": "2026-10-23T09:00:00Z",
    "frame": "TEST_FRAME",
    "quaternion_wxyz": [1, 0, 0, 0]
  }
}
```

- 파일 최대 1 MiB, 센서 최대 64개, 센서당 표본 최대 3600개다. 각 표본 시각은 오름차순 UTC이며 수신 시각 이후일 수 없다.
- 그래프는 선택한 센서의 값과 시험용 상·하한을 표시한다. 초과 목록은 현재 파일과 화면 시간 범위에서 계산되며 운용 경보 이력이 아니다.
- 쿼터니안은 화면 시험 계약에서 `[w,x,y,z]` 순서이며 단위 크기여야 한다. `TEST_FRAME`은 실제 기준 좌표계가 아니므로 실제 CubeADCS 값의 축 변환·자세 방향은 ICD와 좌표계 정의 이후 확정한다.
- 자세 렌더러의 기본 형상은 사각 기둥의 꼭짓점·면 데이터다. 추후 검증된 CAD 메시 어댑터에서 동일한 형상 공급 경계로 교체한다. 현재 임의 CAD 파일 업로드는 지원하지 않는다.

실제 ROS 수신 연결에서는 서버가 TM 패킷·센서 DB를 검증하고 품질, 수신 UTC, 단위·보정식·한계 이력과 쿼터니안 프레임을 확정한 뒤 읽기 API로 제공해야 한다.
