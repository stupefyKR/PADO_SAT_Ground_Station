# 초기 개발방향 요구 추적

2026-10-24 기준. 최초 저장소 문서(`7cb30d3`의 `docs/PADO-SAT_지상국_개발방향.md`)와 현행 [개발방향](PADO-SAT_지상국_개발방향.md)을 대조했다. 대조 시점에 저장소 문서와 Desktop 원본은 같았고, 이번 작업 결과는 저장소 문서에 반영했다. 이 표의 “개발 기준선”은 시험 자료와 로컬 경계에서의 동작을 뜻하며, 실제 위성 운용 수락을 뜻하지 않는다.

## 사용자 결정으로 바뀐 전제

| 최초 제안 | 현행 기준 |
|---|---|
| 서브시스템별 VM 8대, VLAN, 물리 방화벽, 별도 관리 VM | Linux VM 1대의 서브시스템별 Docker 컨테이너. 호스트 UFW와 Docker 정책으로 관제 PC·서비스 경계를 관리 |
| nginx/CivetWeb, 서비스별 PostgreSQL, NAS | 현 로컬 스택은 Python Portal/API·SQLite 시험 저장소·Docker 볼륨. NAS는 후속 과제이며 독립 백업·복원 수락은 유지 |
| S-band 탑재체 원시데이터 수신과 보관 | 현 개발에서 제외. 항우연 S-band의 PASS 예측은 유지 |
| TC 충돌·승인·실제 송출 | 시험 시퀀스와 가상 위성 왕복까지만 연결. 실제 충돌 정책·비행 ICD·승인은 위성개발팀 검토 뒤 연결 |
| 관제 PC 외부 HTTPS | 통제된 시험 LAN의 HTTP 8080 사용. 외부망에는 게시하지 않음 |

## 요구별 개발 상태와 다음 수락 조건

| 초기 요구 | 현재 개발 상태 | 다음 확인·입력 |
|---|---|---|
| DGS만 외부 통신, 다른 서브시스템 외부망 차단 | 로컬 Compose의 DGS-OPS 게이트웨이 한 포트와 내부 네트워크, 런처 정책·거부 시험. 예상 밖 서비스/마운트도 정적 검사 | 실제 VM에서 IPv4/IPv6·DNS·호스트 경유·재부팅 후 거부를 실측하고 DGS별 승인 상대 한정 |
| ROS의 TM 파싱·값·추세·한계·자세 | 가상 위성 시험 EPS/AOCS/GNSS PDU 수신·검증, 60분 추세·한계·사각 기둥 자세 | 실제 OBC TM ICD, 보정·품질·센서 한계, CAD/자세 기준 |
| MPS 패스별 TC 구성 및 ROS 전달 | FDS N13 PASS 조회, 연세대 UHF 시험 시퀀스 저장·ROS 예약·가상 ACK | 충돌·승인·운용 TC는 위성개발팀 정책, CS/CDHS ICD 및 FlatSat 검증 |
| FDS 예측·패스·도플러·궤도력 | TLE/SGP4와 정규화 GNSS 예비 수치 전파, 최대 72시간 N13/N15·ORBIT 표시 | GNSS 다운링크 매핑·정밀도 목표·참조 궤도, 두 안테나 측량 좌표·고각, Hz 도플러용 주파수 |
| N08 FDS→DGS-GS 안테나 지향/패스 요청 | 계산 산출물에서 **비운용 파일·매니페스트**를 별도 출고함에 생성·검증 | 실제 안테나 명령 ICD·수락 상대 확정 전에는 전송 금지 |
| N10 ROS→MPS ACK/BUS_SOH | 시험 예약·TM 스냅샷의 읽기 전용 웹 피드백 | 운용 N10 파일쌍/SFTP·수락 ACK, 실제 SOH/ACK 필드 확정 |
| N13 `ORBITAL_EVENT` | Contact Schedule만 게시 | 이벤트의 정의·계산 기준·수신처 소비 정책 확정 후 별도 계약 |
| N05/N11 검증 입력 | 인증 SFTP N05 pull, N11 완료 파일 수신함, 불변 스냅샷·FDS 반복 계산 도구. 합성 로컬 스택은 별도 경로 | 실제 DGS-NET 상대·계정, OEM719A→OBC TM 매핑 및 배포 연결 |
| TC 승인→signer→DGS 게이트 | C의 합성 경로와 거부 시험. 웹 왕복은 별도 `SIM ONLY` | 2인 승인·재인증·키·비행 패킷·RF 경로·FlatSat 수락 |
| 감사 기록·백업·복구 | journald, 제한된 파일 스냅샷·변조 검출·복원 시험 | 상관 ID를 가진 변경 방지 감사 기록, 독립 백업 매체·일관된 DB 덤프·실제 복원 |
| 외부 DGS-GS/NET/Archive 연동 | 내부 파일/상대 검증 계약과 개발용 시험 경계 | 상대 기관 포트·프로토콜·인증·VPN·파일 ICD가 확보된 뒤 운용 연결 및 현장 시험 |
| ROS 링크·서비스 상태 | 서비스 응답과 시험 TM 최신성, FDS 예측 PASS 시각을 표시. 실측 RF 링크 상태는 없음 | 안테나/모뎀 상태 ICD 및 운용 서비스 헬스 계약 |

## 현 단계의 판정

개발 가능한 누락 경계는 이 작업에서 N08 시험 산출물, MPS의 시험 ACK/SOH 조회, ROS 예측 PASS 시각, Compose 정책 검사로 보강했다. 모든 시험 자료에는 비운용 표시를 유지하고, DGS-GS·Space-Track·외부 SDC 연결과 실제 위성 TC 송출은 열지 않는다. 남은 외부 규격·장비·현장 증거는 [개발방향 14장](PADO-SAT_지상국_개발방향.md#14-미결-사항)과 [운용 전 검토표](TC_TM/REVIEW_GATES.md)에 따른다.
