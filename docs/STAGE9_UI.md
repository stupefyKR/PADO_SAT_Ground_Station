# 단계 9 ROS·MPS 화면 구조

2026-10-23 사용자와 합의한 화면 기준선이다. 세부 시각 디자인과 운용 동작은 후속 검토에서 다듬는다.

## ROS

| 화면 | 관제자가 확인하는 것 | 현재 연결 |
| --- | --- | --- |
| 현황·경보 | 계측 출처·갱신 상태, 최신 표본의 한계 초과 센서, 선택 구간의 과거 초과 이력 | 명시적 시험 한계와 `TEST_ONLY_TM_SNAPSHOT` |
| TM·자세 | 센서 검색·값·시간 그래프·한계 대역, 쿼터니안 기반 사각 기둥 자세 | 게시된 시험 스냅샷, 수동 시험 JSON, 합성 예시 |
| TC 준비·예약 | MPS 시험 시퀀스 쌍 검증·단계 확인·PASS 내부 예약 초안 | 파일 수동 반입 및 ROS 초안 DB |

현재 상태와 이력은 분리한다. 게시된 시험 TM이 5분 이상 오래됐거나 새 입력을 확인할 수 없으면 최신 표본을 현재 정상/경보로 표시하지 않는다. 현황의 초과 센서를 선택하면 해당 TM 그래프로 이동한다. 실제 위성 TM, 운용 경보, TC 자동 실행·송출 기능은 연결되지 않는다.

## MPS

한 화면에서 `01 PASS 선택 → 02 시험 TC 후보 구성 → 03 계획 검토` 순서로 작업한다. 1단계는 검증된 FDS N13 일정의 두 지상국 PASS를 모두 보여준다. 현재 PDR 기반 TC 초안은 UHF 범위이므로 2단계는 **연세대 UHF PASS에서만** 이름과 순서 편집을 허용한다. 대전 S-band PASS는 조회 전용이며 서버도 후보 저장을 거부한다. 3단계는 PASS 경계, 후보 순서와 저장 리비전을 확인한다.

명령 인자·실행 시각 저장, 충돌 판정, MPS→ROS 자동 전달, 승인·운용 출력은 이번 화면 구조 정리 범위에 넣지 않았다. 실제 CS/CDHS ICD 및 위성개발팀과의 정책 검토 뒤 별도로 연결한다.

## 후속 화면 검토 항목

- 실제 관제 모니터 해상도에서 밀도·스크롤·키보드 동선을 확인한다.
- 센서 ICD가 확정되면 그룹·단위·보정·한계의 표시 규칙과 다중 그래프 구성을 정한다.
- CAD 형상과 자세 기준 좌표계가 확정되면 사각 기둥 뷰의 모델 어댑터를 교체한다.
- TC 승인·ACK 규격이 확정되면 시험 초안과 운용 화면의 상태 전이를 별도로 설계한다.
