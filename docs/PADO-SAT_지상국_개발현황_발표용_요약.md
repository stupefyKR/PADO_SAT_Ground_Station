# PADO-SAT 지상국 개발 현황 — 발표용 요약

> 2026-10-25 기준. 현재 구현한 **비운용 개발·시뮬레이션 기능**을 높은 수준에서 정리했다. 실제 위성 또는 외부 지상국과의 운용 연동이 완료됐다는 의미는 아니다.

## 발표 핵심 메시지

PADO-SAT 지상국은 외부 지상국에서 얻는 위성 자료를 **궤도 예측 → 교신 일정 수립 → 위성 상태 관제 → 명령 결과 확인**으로 연결하는 경희대학교의 임무운영 소프트웨어다. 현재는 실제 위성 대신 가상 위성을 사용해 이 흐름을 웹 화면과 분리된 서브시스템 사이에서 시험할 수 있는 기준선을 구축했다.

## 전체 구성

단일 Linux VM에서 FDS, MPS, ROS, 웹 포털과 시험 구성요소를 역할별 컨테이너로 분리한다. 운영자는 내부망의 관제 PC에서 공통 웹 화면에 접속한다. **외부 자료 교환은 DGS만 담당한다**는 원칙을 적용하며, 현재 웹 시험의 진입점과 장래의 안테나·외부 자료 연동 경로는 구분한다. 실제 항우연·연세대 안테나 연결은 아직 열지 않았다.

| 구성요소 | 현재 확인할 수 있는 기능 |
|---|---|
| **FDS — 궤도 예측** | TLE의 SGP4 전파와 시험 GNSS 상태의 예비 수치 전파를 통해 최대 72시간의 궤도력, 두 지상국의 PASS 일정, 도플러 예측을 생성한다. 유효한 GNSS가 있으면 이를 우선하고, 없거나 오래되면 TLE를 사용한다. 현재 주파수와 도플러 값은 시험 설정이다. |
| **MPS — 임무 일정** | FDS가 예측한 연세대·대전 PASS와 경로를 조회한다. 연세대 UHF PASS에 한해 시험용 TC 순서·인자·실행 시각을 구성하고 ROS 시험 영역으로 전달한다. |
| **ROS — 위성 관제** | 시험 TM에서 센서 변화와 한계 초과를 그래프로 확인하고, 쿼터니안 기반의 간단한 위성 자세를 보여준다. MPS 시험 시퀀스를 가상 위성에 예약하고 응답 상태를 확인한다. |
| **ORBIT — 위치 확인** | 현재 위성 위치를 3D 지구와 2D 지상궤적에 함께 표시한다. 주야간, 향후 궤적, 연세대·대전 지상국의 예상 PASS와 polar plot을 확인할 수 있다. |
| **DGS — 외부 경계** | 자료 방향·유형을 정의하고 시험 프레임 및 파일의 형식과 무결성을 검증하는 기반을 마련했다. 실제 외부 상대와의 운용 송수신 서비스는 아직 연결하지 않았다. |

## 가상 위성을 이용한 통합 시험

실제 PADO-SAT TLE와 TM이 없는 상태에서도 화면과 서브시스템 사이의 동작을 검증할 수 있도록, **고도 약 500 km·LTAN 06시의 가상 SSO 궤도**를 사용한다. PDR 자료를 바탕으로 비운용 TC/TM 패킷 초안을 정리했고, 가상 위성은 이 시험 형식으로 GNSS·전력·온도·자세 TM을 주기적으로 생성한다.

```text
가상 위성 TM → 시험 수신·검증 → ROS 센서·자세 화면
                            └→ FDS 궤도·PASS 예측 → ORBIT / MPS
MPS 시험 시퀀스 → ROS 예약 → 가상 위성 → 명령 결과 TM → ROS 상태
```

이 시험으로 **데이터 수신·파싱·표시, 궤도 결과의 화면 반영, PASS별 명령 준비와 응답 확인**을 하나의 흐름에서 점검한다. 가상 위성의 응답은 소프트웨어 왕복 결과이며 실제 RF 교신 성공을 뜻하지 않는다.

## 보안 설계와 현재 적용 범위

- ROS·MPS·FDS는 외부망에 직접 접속하지 않고, 컨테이너별 네트워크와 자료 접근 권한을 제한한다. 관제 웹도 정해진 내부망 진입점으로만 제공한다.
- 로그인·역할별 접근 제어와 데이터 형식·무결성 검사를 적용하고, 시험 명령은 실제 위성 송출 경로와 분리한다.
- 장래 운용 TC는 승인·인증을 거친 뒤 **DGS 최종 송출 게이트**에서 내용과 시간창을 재검사하도록 설계한다. 현재 게이트는 합성 패킷 시험 수준이며 실제 외부 송신 기능은 없다.

## 진행 수준과 다음 단계

인터페이스·통신·파일 교환·보안 시험의 개발 기준선과 FDS·MPS·ROS·ORBIT의 비운용 웹 흐름을 마련했다. 가상 TM 수신과 제한된 TC/응답 왕복은 내부 통합 시험으로 확인했으며, 전체 VMware 배포와 관제 PC 화면을 포함한 최종 수락은 남아 있다.

운용 전환에는 **비행용 TC/TM ICD와 센서 기준값, GNSS 다운링크 매핑, 지상국별 실제 연결 규격·안테나 설정, 궤도 예측 정확도 검증, 명령 충돌·승인 정책, 현장 보안·복구 시험**이 필요하다. 항우연 S-band 탑재체 데이터 수신과 NAS 연동은 현재 개발 범위에서 제외했다.
