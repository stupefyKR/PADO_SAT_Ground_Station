# TC/TM 초안에서 운용 인터페이스로 넘어가기 위한 검토표

이 표는 [설계 초안](DESIGN.md)과 현재 구현을 대조한 작업 인계 목록이다. PDR의 예비 수치와 실제 위성·지상국 구성에서 확정된 값을 구분한다. 아래 외부 입력이 없는 칸은 추정으로 채우지 않는다.

| 항목 | 현재 구현·PDR 근거 | 확정에 필요한 자료·시험 |
| --- | --- | --- |
| TC/TM 바이트 배치 | 200 B 응용 PDU 초안, 58 TC/16 TM, 36 TC 인코딩 가능 | CS·CDHS 승인 ICD, 비행 FSW와 지상 코덱 양방향 golden vector |
| CSP/AX100 | PDR의 CSP v1·AX100 Mode 5·비콘 길이 언급 | 실제 CSP 노드·포트, MTU 포함 범위, AX100 복조 바이트 dump, RF/CSP/PDU CRC 경계 |
| TC 인증·ACK | PDR의 OBC 명령 인증 요구, 초안 `COMMAND_RESULT` | 알고리즘·키·서명 범위·재전송 규칙·ACK/오류 코드·명령 큐·취소·만료 규칙 |
| TC 인자·권한 | 인자 확실한 36종만 시험 코덱 지원; 22종 fail closed | 58종 인자/enum/전제 조건/허용 역할·위험 승인표, CS·CDHS 통합 시험 |
| ROS TM 그래프 | 시험 스냅샷과 초안 TM 변환기, 명시적 시험 한계표 | 실제 센서 TM ID/필드/단위/보정식/한계 이력, 수신 품질·시각 기준, 경보 수락 기준 |
| ROS 자세 | 초안 `AOCS_STATE` quaternion 및 `TEST_FRAME` 미리보기 | CubeADCS→OBC 축·프레임·순서·부호, CAD 모델 좌표계와 시험 표본 |
| GNSS→FDS | 초안 `GNSS_PVT`→검증된 N11 파일 쌍·FDS 우선 선택 시험 | OEM719A 로그→OBC→다운링크 TM 실배치, 상태 비트·ITRF/시각 계약, 실제 수신 dump |
| FDS PASS·도플러 | TLE/SGP4 및 예비 GNSS 수치 전파 구현. 시험용 좌표·고각 기준·주파수는 설정으로 분리 | 실제 컨택 시각 검증에는 안테나 측량 좌표·지평선 mask가 필요. Hz 도플러 확정에는 할당 RF 주파수가 필요. 범위율(m/s)은 주파수 없이 계산 가능 |
| FDS 정밀 전파 | 현재 중력장+태양/달 중력 모델에는 위성 질량이 필요하지 않음 | 정밀도 목표와 참조 궤도가 먼저 필요. 항력·SRP 도입 시 비행 질량·유효 면적·Cd/Cr·대기 자료를 함께 확정 |
| MPS 충돌·시퀀스 | N13 PASS별 초안 TC 이름·순서 저장; 인자·실행 시각 없음 | 위성 자원/모드 충돌 정책, 명령 소요·전송량·ACK 타이밍, 승인 명령 DB |
| N13/N15 실제 교환 | 로컬 출고함, 인증 SFTP 단발 도구, 반복 송신·로컬 전송 receipt·재시도 구현 | 수신 상대 주소·계정·호스트 키, **수신측 ACK 계약**, 현장 재시도 운영 시험 |
| DGS-GS 원시데이터 임시 영역 | S-band payload 수신 구현 범위 밖; 보관 정책 미정 | 저장 용량·보관시간·회수 주기, Archive 확인·삭제 기준 |

예비 질량·링크 버짓 값은 현재 TC/TM 패킷 및 FDS 계산의 선행 조건이 아니다. 실제 VM 배포, UFW·컨테이너 네트워크, 독립 백업·복원, FlatSat 시험은 개발 완료 뒤 배포 수락 단계에서 수행한다. NAS와 S-band payload 데이터 수신은 사용자의 결정에 따라 현 범위에서 제외한다.
